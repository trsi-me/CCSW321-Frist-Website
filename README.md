# CCSW321 - Frist Website

## 1. ما هو المشروع؟

موقع ثابت باللغة الإنجليزية لتعليم HTML. عنوان الصفحات: Learn HTML - From Zero to Pro. اسم المجلد `CCSW321 - Frist Website`، وكلمة Frist مكتوبة بهذا الشكل داخل اسم المجلد. الصفحات أربع: الرئيسية، من نحن، تواصل معنا، ودرس HTML.

## 2. لماذا يوجد هذا المشروع؟

استنتاج من الكود: الصفحات تقدم تعريفاً تعليمياً بـ HTML مع نموذج تواصل وجدول أسماء. المقرر CCSW321 ظاهر في اسم المجلد فقط، والنصوص داخل HTML تتحدث عن تعلم HTML من الصفر.

## 3. من يستخدمه؟

الزائر الذي يفتح الصفحات في المتصفح. جدول About Us يعرض أربعة صفوف بأسماء ثابتة: Student 1 حتى Student 4، وأدوارها مكتوبة Specific Part وتخصصها Web Development. حسابات دخول غير موجودة.

## 4. ماذا يستطيع النظام أن يفعل؟

- عرض نص ترحيب في `HTML/index.html`.
- عرض جدول الفريق في `HTML/about-us.html` مع روابط Twitter وLinkedIn وInstagram وGitHub وFacebook على النطاقات العامة فقط.
- نموذج تواصل في `HTML/contact-us.html`: الاسم، الجنس (Male/Female)، الهاتف، تاريخ الميلاد، البريد، لغة التواصل (Arabic أو English)، الرسالة، وزر Send.
- صفحة `HTML/lessons.html` تشرح وسوم HTML نصياً: h1 وp وdiv وspan ثم الجداول والقوائم والنماذج ثم header وnav وsection وarticle وfooter، مع الصور والروابط والوسائط.

## 5. كيف يعمل النظام؟

المتصفح يفتح ملف HTML. كل صفحة تكرر الترويسة نفسها وقائمة التنقل والتذييل. التنسيق يأتي من `CSS/style.css`. النموذج بلا سمة action وبلا method، لذلك الإرسال يبقى داخل الصفحة.

## 6. أمثلة واقعية

الزائر يفتح `HTML/index.html` فيقرأ فقرة الترحيب. ينتقل إلى Learn HTML فيقرأ شرح الوسوم. يفتح Contact Us ويملأ Name وEmail وMessage ثم يضغط Send. المتصفح يطبق التحقق required على الحقول، ولا يوجد خادم يستقبل البيانات.

## 7. رحلة المستخدم

1. فتح `HTML/index.html`.
2. اختيار Home أو About Us أو Contact Us أو Learn HTML من `nav`.
3. في التواصل: تعبئة الحقول المطلوبة.
4. الضغط على Send.
5. النتيجة الظاهرة: البقاء في الصفحة نفسها. حفظ في قاعدة بيانات غير موجود في الملفات الحالية.

## 24. Security

الروابط الخارجية في About Us تحمل `target="_blank"` و`rel="noopener noreferrer"`. حقول النموذج عليها required. CSRF وتهيئة كلمات مرور وترويسات أمان وملفات جلسة غير موجودة في الملفات الحالية. أيقونة المتصفح `link rel="icon"` غير موجودة في الصفحات.
